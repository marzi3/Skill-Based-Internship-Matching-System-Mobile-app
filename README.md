# Internship Matching Platform Backend

Node.js/Express backend for the internship matching platform.

## Getting Started

```bash
npm install
npm run dev
```

## Matching Engine — How It Works

This project features a powerful, automated **Matching Engine** that connects students with the best internship opportunities. It functions like an expert recruiting assistant: it reads a student's profile and an internship's requirements, then assigns points based on how well they align.

### The Rule System
Instead of a rigid "pass/fail" approach, the engine uses a flexible scoring system divided into priority categories:

1. **Mandatory Requirements (Dealbreakers)**
   If a student is missing a "mandatory" skill, applying to a field outside their degree, or has a GPA below the minimum threshold, the engine immediately disqualifies the match.
2. **Core Skills (The Heavy Lifters)**
   Students earn significant points for every skill that matches what the employer is looking for. Extra points are awarded for advanced proficiency or having a high overall percentage of the desired skills.
3. **Profile Strength (The Basics)**
   A complete profile (with a resume, portfolio, and filled-out bio) and a matching education level give students a solid foundation of bonus points.
4. **Context & Preferences (The Perfect Fit)**
   The engine considers geographical location (or remote status), duration preferences, industry alignment, and prior experience to boost matches that truly fit the student's and employer's context.
5. **Engagement (The Active Shapers)**
   Listings that were posted recently or whose deadlines are quickly approaching get a minor visibility boost. Active students and verified employers also receive slight bumps to reward platform engagement.

### Match Tiers
Once the points are added up, the system normalizes the score from 0 to 100% and assigns a tier:
* **EXCELLENT** (80%+)
* **GOOD** (60-79%)
* **FAIR** (40-59%)
* **WEAK** (20-39%)
* **POOR** (<20%)

Every match generated by the system includes a transparent "Explanation Log" so that users can see exactly *why* a certain tier was assigned and which rules contributed points.
